Symbolic Music Generation with LSTMs

Quick reference: how it works, end to end1 / 2

The idea: treat music like text. Every note, chord or silence becomes a token, and an LSTM learns to predict the next token. To compose, it predicts one token, appends it, and repeats. All numbers below are the final model (v5, configs/adl_mixed.yaml).

1Parse and quantizesrc/data/parse.py
MIDI file → Piece (list of NoteEvent(pitch, start, duration, velocity), times in beats)
  • Reads with pretty_midi; merges all non-drum tracks into one stream (all ADL tracks are piano).
  • Converts seconds → beats through every tempo change (tempo_map), then snaps start and length to a 16th-note grid (0.25 beat).
  • Drops: pieces with a time signature other than 4/4, 3/4, 2/4; notes < 0.125 beat; pieces < 50 notes. Merges the same pitch struck twice at once.
  • Style label = top folder name (Classical / Jazz / Blues). 11,073 ADL files → 2,019 in these genres → 1,654 kept (1.88 M notes).
2Split by pieceaugment.split_pieces
  • Fixed shuffle (seed 1337) → 80 / 10 / 10 % train / val / test, by whole piece.
  • Drops val/test pieces that duplicate a training piece, even transposed → 1,324 / 162 / 161.
  • Done before augmenting, so no version of a held-out song leaks into training.
3Augment (train only)augment.transpose_augment
  • Adds copies shifted −6 … +6 semitones (13 keys). A copy is dropped if any note leaves piano range 21–108.
  • 1,324 → 15,745 training pieces. Teaches patterns independent of key.
4Encode to symbolssrc/data/encode.py
Piece → ["<STYLE:Jazz>", "60.64.67", "<REST:2>", "62", …]
  • note_chord: all notes starting together = one symbol, pitches joined by dots. Each note/chord symbol advances the clock one 16th.
  • Silence = one run-length rest <REST:k> (k = 2…16 steps; <REST> = 1). Cut rests from 56 % to 36 % of tokens.
  • No duration in the symbol (it would make 363,455 symbols). Durations are rebuilt at playback (step 10).
  • Other schemes (config switch): interval, pitch_duration, event.
5Vocabularysrc/data/vocab.py
  • Symbol ↔ integer id, from the training split only, in sorted() order. Reserved: <PAD>0 <UNK>1 <BOS>2 <EOS>3 <REST>4.
  • Symbols seen < 10 times → <UNK> (~4 % of tokens). Result: 37,020 symbols, 12.8 M training tokens.
  • Saved as vocab.json beside the model; the model never runs with a different vocabulary.
6Windows and batchessrc/data/dataset.py
  • Each piece is cut into 256-token windows every 128 tokens (half overlap), plus one window aligned to the end. Never crosses into another piece.
  • Teacher forcing: y = x shifted one step left, so every position is a target (256 per window).
  • Shuffled batches of 48 → tensors x, y : [48, 256].
7Model: MusicLSTMsrc/models/lstm.py
LayerShapeParams
Embedding37,020 → 2569.5 M
LSTM × 3 (dropout 0.3 between)256 → 512 → 512 → 5125.8 M
Dropout 0.3 · Linear · ReLU512 → 2560.13 M
Adaptive softmax (head 2,000 · 8,000 · 27,020)256 → 37,0201.48 M
Total16.87 M
  • Output [B, 256, 37,020]: a probability for every symbol at every position.
  • Init: orthogonal recurrent weights, forget-gate bias 1 (the cell starts out remembering).
8Training loopsrc/train.py
  • Per batch: forward → cross-entropy over all positions (<PAD> ignored) → backprop through time → clip gradient norm to 5 → Adam step (lr 0.001).
  • Per epoch: validation loss. Better → save best.pt. Not better → halve the LR; 3 epochs without improvement → stop.
  • v5: best val loss 3.615 at epoch 3, stopped at epoch 6; ~106 s/epoch on an RTX 5070 (~11 min total).
9Generategenerate.py · sampling.py
  • Load best.pt + vocab.json (refuses if the data hash differs). Prime with a 256-token excerpt from the validation split.
  • Loop 500×: get next-token probabilities → ban <PAD BOS EOS UNK STYLE> → divide by temperature 0.9 → random draw → feed back (hidden state carried, one token per step).
  • Writes <name>_T0.90_seed<seed>_<i>.mid + .txt of tokens. --seed <seed> reproduces it.
10Decode and render audiodecode.py · render_audio.py
  • Tokens → notes (each one 16th long) → fill_durations lets each note ring until the next onset (max 4 beats). This is what removes the staccato sound.
  • render_audio.py: numpy piano synth (decaying partials, reverb, −14 dBFS) → 44.1 kHz stereo WAV. --instrument piano|epiano|organ.
11Evaluatesrc/evaluate.py
  • Scores generated MIDI against real music: in-key 0.884 (real 0.84–0.88, random 0.583), plus variety, rhythm, repetition and copy checks. See page 2.
